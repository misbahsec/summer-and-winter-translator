# Summer-and-Winter Image Translator

Unpaired image-to-image translation between summer and winter landscapes using CycleGAN in PyTorch, featuring a Gradio web interface.

## Features
- **CycleGAN Architecture**: Translates summer images to winter and vice versa without requiring paired training data.
- **Gradio Web Interface**: Interactive user interface for real-time image translation and testing.
- **Pre-trained Weights Integration**: Seamlessly loads trained generator weights for fast inference.
