## Pre-trained Models

The pre-trained model weights (`generator_A2B.pth` and `generator_B2A.pth`) are hosted on Hugging Face Model Hub.

1. Download both model files from the Hugging Face Repository: [misbahsec/cyclegan-summer2winter2summer](https://huggingface.co/misbahsec/cyclegan-summer2winter2summer)
2. Place them inside the `cyclegan-summer2winter-pytorch-default-v1/` directory in your local project folder.
